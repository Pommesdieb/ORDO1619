# Playground

Experimental design work lives here.

Nothing in `Playground/` is normative merely because it exists. Competing approaches are allowed and expected during design conception.

## Purpose

The Playground is the evidence-generating surface for the ORDO Public Design Language.

Experiments may test typography, syntax, spacing, hierarchy, diagrams, labels, relations, boundaries, or other representation mechanisms against real ORDO semantics.

## Non-normative status

An experiment in this directory:

- does not redefine ORDO semantics;
- does not become part of the Public Design Language automatically;
- does not imply Release Candidate status;
- does not imply Public Release status;
- may be replaced or discarded without compatibility guarantees.

## Promotion criteria

Promotion out of Playground requires evidence of:

1. semantic correctness;
2. demonstrated communicative value;
3. carrier independence where applicable;
4. consistency with established design principles;
5. sufficient reuse or recurring need to justify a stable rule;
6. explicit promotion into the appropriate design-system layer.

## Current experiment direction

The first planned experiment concerns **Identity** and should test how Entity Identifier, Workspace ID / WID, Interaction Identity, and non-Entity identifiers can remain visibly distinct while still reading as one ORDO design language.

See [`../Semantics/Identity.md`](../Semantics/Identity.md).
